# Mini Portfolio - Build Projects

#### What You'll Create (Project Idea): Sales Data Analysis

**Objective:** Build an interactive dashboard using real or sample sales data

**Topics Covered:**
- Formatting & Data Entry: Currency, dates, clean structure
- Formulas: SUM, AVERAGE, COUNT, IF, IFERROR
- Data Validation: Drop-downs for category, region, month
- Conditional Formatting: Highlight top performers, trends
- Pivot Tables & Charts: Summarize sales by product, region, time

#### Super-Store Data Analysis
**Objective :**
- Vrinda Store wants to create an annual sales report for this year. So that Vrinda can understand their customers and grow their sales in the upcoming years.

**Sample Questions**
1. Compare the sales and orders using a single chart
2. Which month got the highest sales and orders?
3. Who purchased more, men or women?
4. What are different order status in this year?
5. List of top IO states contributing to sales
6. Relation between age and gender based on number
7. Which channel is contributing to maximum sales?
8. Highest selling category
