# Chapter - Why SQL?

- SQL - Structured Query Language
- MYSQL - One of the DB Tools

#### Why to rely on these DB Tools?
- Excel is only local
- Excel can store onlyu upto 10Lakh Rows & 16384 Columns
- If you load more than 50,000 Rows, Excel will open tomorrow :)
- Due to this limitations, companies are relying on Cloud Databases

#### DBMS - Database Management System
- Types 
  - RDBMS - Relational Database Management System
    - It Handles only structured data 
      - Rows and Columns
  - NRDBMS - Non Relational Database Management System
    - It handles only unstructured data 
      - Audio, Video, Text, Images


| RDBMS | NRDBMS |
| --- | --- |
| Relational Database Management System | Non Relational Database Management System |
| It Handles only structured data | It handles only unstructured data |
| Rows and Columns | Audio, Video, Text, Images |
| Tools <br> 1. SQL WorkBench <br>2. Oracle DB <br>3. MS SQL Server <br>4. Postgre SQL | Tools <br> 1. MongoDB <br>2. Apache Cassandra <br>3.Amazon Dynamo DB |
